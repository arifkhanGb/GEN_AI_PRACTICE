
# RepoMind

AI-powered documentation and chat for GitHub repositories.

## Tech Stack

- Python 3.12+
- FastAPI
- Inngest
- LangGraph
- LangChain
- Qdrant
- PostgreSQL

## Local Development

Activate the virtual environment:

```powershell
.\.venv\Scripts\Activate.ps1
```

Install the project:

```powershell
python -m pip install -e ".[dev]"
```
